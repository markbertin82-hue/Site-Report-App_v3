# Site Job Reporter V4.2

New in V4.2:
- Edit job details after creation (customer, job number, site, address, contact, machine, engineer and reason).
- Edit saved written notes and equipment entries by tapping them.
- Separate PC screenshot / image upload beside camera capture.
- Engineer settings on home screen: default name saved locally, copied into each new job; per-job name editable.
- Site address in job creation, editor, report and ChatGPT prompt.
- Signed off permit appended to each job checklist (including existing jobs).
- Tap photos (including snag photos) to enlarge; zoom buttons in image viewer.
- Shorter snag update placeholder.

Upgrade: Export a JSON backup before uploading these seven files to the root of your existing GitHub Pages repository. Keep the same URL to retain local IndexedDB records. Close/reopen the app online after deployment. Do not clear site data.

Notes: Default engineer name is saved on each device independently; job data is not synced between devices. Report prompt includes engineer and site address, so check confidentiality before pasting it into ChatGPT. Photos may consume significant local storage. Existing completed jobs need reopening before editing.
