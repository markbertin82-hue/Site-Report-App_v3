# Site Job Reporter V4.1

New dedicated Snags tab for commissioning, service and modification jobs.

- Add snag description, location/equipment and priority.
- Status Open / In Progress / Resolved / Closed.
- Timestamped investigation and corrective-action notes.
- Photos attached to individual snags.
- Snags persist across working days.
- Snags included in report preview and AI prompt.
- Snag count in the tab.

Update your existing GitHub Pages repository root with all files. Export a backup before upgrading. This version retains the same IndexedDB database as V4 and should preserve your records on the same website. Never clear browser data to force an update.

Limitations: Snag photos can consume significant local storage; export backups regularly. The app has no OneDrive sync and should not be used with confidential company/customer data without approval.
