# Site Job Reporter V4.3
Changes from V4.2:
- Saved notes and equipment details can be edited without starting a working day, including completed jobs.
- Edit Job Details button moved beside the back-to-Jobs button, also available for completed jobs.
- Job action buttons retain a three-column layout.
- Photo viewer zoom centers on current viewport and supports scrolling/swiping in both directions while zoomed. Use Zoom +, Zoom -, Fit.
- Legacy notes/equipment without IDs receive stable IDs for editing.

Install by replacing the existing files in the same GitHub Pages repository. Back up your job data first. Wait for deployment and reopen online. Do not clear website data. Data is stored locally per device; no cloud sync.
